# Боты Сферы

Боты — это обычные аккаунты с глобальным типом `bot`: они участвуют в диалогах
и каналах наравне с людьми, их сообщения проходят те же фильтры контента, а
имя всегда заканчивается на `_bot` и помечается бейджем **BOT**.

## Типы аккаунтов

`sfera_auth.User.account_type` — глобальная роль аккаунта:

| Значение | Кто это |
|---|---|
| `user` | обычный пользователь (по умолчанию) |
| `bot` | бот; отображается с суффиксом `_bot` и бейджем BOT |
| `admin` | сотрудник инстанса; бейдж ADMIN |

Роли внутри серверов (`owner` / `admin` / `member`) остались независимыми.

## Сфероник

Системный бот-регистратор. Открывается из **Исследовать Сферу → Инструменты
от разработчика → Сфероник**; дальше это обычный личный диалог.

| Команда | Что делает |
|---|---|
| `/newbot` | создаёт аккаунт бота и выдаёт ключ (показывается один раз) |
| `/mybots` | список ваших ботов и их команд |
| `/token <бот>` | выпускает новый ключ, старый сразу отзывается |
| `/setcommands <бот>` | задаёт список команд (`команда - описание`, по строке) |
| `/addbot <бот>` | добавляет бота на ваш сервер (только там, где вы владелец или админ) |
| `/removebot <бот>` | убирает бота с сервера; сообщения бота остаются |
| `/deletebot <бот>` | удаляет бота: ключ отзывается, **переписки остаются** |

Юзернейм нормализуется автоматически: `weather` → `weather_bot`.

## Нодовый редактор

**Исследовать Сферу → Инструменты от разработчика → Нодовый редактор бота.**
Открывается по ключу бота, который должен принадлежать вам. Работает мышью и
пальцем: узлы перетаскиваются, холст панорамируется, связь собирается в два
касания (порт → узел), на узком экране панели превращаются в нижние шторки.

Узлы: «Команда», «Сообщение» (триггеры), «Ответить», «Условие», «HTTP-запрос»,
«Пауза», «Стоп». В тексте доступны подстановки `{text}`, `{args}`, `{user}` и
имена переменных HTTP-узлов.

* **Сохранить** — записывает схему и регистрирует команды на сервере (именно
  они появляются в кнопке команд рядом с полем ввода).
* **Скачать** — отдаёт ZIP с готовым проектом на Python, C++ или Rust: исходник,
  конфиг сборки, README и `bot.flow.json` со схемой. Проект запускается на
  вашем сервере, ключ передаётся через `SFERA_BOT_TOKEN`.

## Bot API

Публичная часть API живёт под `/api/bots/api/` и не требует заголовка
`X-Ionik-Client`. Аутентификация — `Authorization: Bot <ключ>`.

| Метод | Эндпоинт | Назначение |
|---|---|---|
| GET | `/api/bots/api/me/` | профиль бота |
| GET | `/api/bots/api/chats/` | где бот присутствует |
| POST | `/api/bots/api/commands/` | опубликовать команды |
| GET | `/api/bots/api/updates/?offset=&timeout=` | длинный опрос обновлений |
| POST | `/api/bots/api/send/` | отправить сообщение |
| POST | `/api/bots/api/edit/` | переписать своё сообщение |
| POST | `/api/bots/api/delete/` | удалить своё сообщение |

`offset` — id последнего обработанного обновления: всё до него включительно
удаляется на сервере, поэтому обработанное не приходит повторно. `timeout` —
до 45 секунд ожидания на пустой очереди.

Владельческая часть (JWT пользователя):

| Метод | Эндпоинт |
|---|---|
| GET/POST | `/api/bots/` — список / создание |
| DELETE | `/api/bots/<id>/` — удалить (ключ отзывается, диалоги остаются) |
| POST | `/api/bots/<id>/token/` — новый ключ |
| POST | `/api/bots/<id>/commands/` — команды |
| GET/PUT | `/api/bots/<id>/flow/` — схема нодового редактора |
| POST/DELETE | `/api/bots/<id>/guilds/<guild_id>/[remove/]` — добавить/убрать бота на сервере |
| POST | `/api/bots/unlock/` — обменять ключ на профиль (открывает редактор) |
| GET | `/api/bots/sferonik/` — диалог со Сфероником |
| GET | `/api/bots/commands/?user_id=\|channel_id=` — команды для кнопки у поля ввода |

## Библиотеки

| Язык | Каталог | Зависимости |
|---|---|---|
| Python 3.9+ | [`bot-sdks/python`](../bot-sdks/python) | нет |
| Rust 2021 | [`bot-sdks/rust`](../bot-sdks/rust) | ureq, serde |
| C++17 | [`bot-sdks/cpp`](../bot-sdks/cpp) | libcurl |

У всех трёх одинаковая модель: `command()`, `on_message()`, `send()`/`reply()`,
`set_commands()`, `poll()`/`dispatch()` и блокирующий `run()`.

## Как бот попадает в чат

* **ЛС** — бот появляется в списке диалогов сразу после создания: контакт
  добавляется автоматически, потому что принять заявку в друзья боту некому.
* **Сервер** — владелец бота добавляет его командой `/addbot` у Сфероника или
  через `POST /api/bots/<id>/guilds/<guild_id>/`. И то и другое требует роли
  владельца или админа именно на этом сервере, так что на чужой сервер бота
  добавить нельзя.

Заявка в друзья боту не отправляется: принять её некому, поэтому контакт
создаётся сразу. Сфероник в списке ЛС не показывается — он открывается
иконкой в панели серверов.

В канале с несколькими ботами команда адресуется конкретному: `/help@my_bot`.

## Ограничения

* До 20 активных ботов на аккаунт.
* Сообщение бота — не длиннее 4000 символов.
* Бот не может писать в чат, участником которого он не является.
* Бот не запускает другого бота: сообщения от аккаунтов с `account_type='bot'`
  в очередь обновлений не попадают.
