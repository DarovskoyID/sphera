# Подключение исходного UI к распределённым поинтам — 20 ноября 2026

Все семь VPS установили full-api-complete-v4: исходный React UI, расширенные маршруты, встроенные модули и единый ASGI-процесс HTTP/WebSocket на каждом поинте. Общей SQL-базы и Redis нет. Установка TURN исправлена отдельным подписанным full-api-turn-v6 на всех семи VPS. Швейцарская загрузка v5 прерывалась по сети; повторная загрузка и v6 успешны.

Подключены настройки, профиль, друзья и запросы, блокировки, устройства и отзыв локальных сессий, безопасная загрузка и выдача изображений/эмодзи, экспорт, каталог модулей. Установлено 11 встроенных модулей; коммерческие права на изменения сохраняются и не обходятся. Новые URL не означают, что все прикладные сценарии модулей уже проверены.

Профиль сохраняет локальные сведения на выбранном поинте. Смена сетевого имени подписывается владельцем в браузере, пароль на сервер не отправляется. Диалог создаётся по общей сетевой идентичности с подписью устройства. Сигналы звонков подписываются устройством и пересылаются между самостоятельными поинтами.

На всех семи поинтах прошли настоящая регистрация и проверка десяти API с JWT, а также запись и чтение профиля. Отдельно подписанное владельцем новое имя версии 2 подтверждено в каталогах всех семи поинтов. Локальные проверки TypeScript, JWT/DRF/Channels и подписи действий прошли.

Проверка звонка между Казахстаном и Великобританией прошла: оба соединения connected, только TURN relay, с обеих сторон получены искусственные аудио- и видеокадры. Не использовались камера и микрофон пользователя. Это проверка серверного пути и клиентских подписей, а не ручная проверка всех кнопок браузера.

Переход со старой базы v8 проверен отдельно. Перед согласованием порядка миграций создаётся приватная SQLite-копия. Применённые миграции не подделываются. Если обнаружены старые guild-данные, автоматический переход останавливается для отдельного переноса. Это ограничение относится к обновлению старых установок, а не к новой пустой базе.

## Что ещё не завершено

- Распределённая передача SDK-ключей и шифрованных сообщений: соответствующие capabilities остаются false. Старый локальный механизм одноразовых ключей не включён как сетевой.
- Контакты, настройки и дополнительные сведения профиля пока относятся к одному поинту. Глобальные аккаунты, имя и идентичности диалогов относятся к сети.
- Сетевое удаление аккаунта и диалога пока явно недоступно; отсутствующая функция не выдаётся за успешную операцию.
- Установка нового произвольного поинта не проверена на текущем пакете целиком; обновлены существующие семь.
- Коммерческое управление модулями требует отдельного рабочего сервиса лицензий.
