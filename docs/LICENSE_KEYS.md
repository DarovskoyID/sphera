# Выпуск ключей модулей

Ключи выпускаются оператором на сервере компании в отдельном сервисе лицензий. Откройте SSH-терминал этого сервера и перейдите в `/opt/sfera-commercial`.

Пример: новый ключ на все 15 модулей со сроком до 19 октября 2027 года, 00:00 по Москве. Дата в примере — параметр; замените её на нужный срок **до** запуска.

```sh
cd /opt/sfera-commercial
docker compose exec commercial-api python manage.py issue_license --modules all --expires-at "2027-10-19T00:00:00+03:00" --label "Владелец сервера" --key-file /app/state/owner-license.json
docker compose exec commercial-api cat /app/state/owner-license.json
```

Скопируйте значение `license_key` из выведенного JSON и вставьте его в окно «Установить» на карточке. Активацию выполняет администратор узла. Все пользователи этого узла получают доступ с сохранением своих обычных прав на данные.

Для одного модуля замените `all`, например, на `office`. Для набора — `office,whiteboard,planner`. При выпуске следующего ключа задайте другое имя файла; команда не перезаписывает уже существующий файл.

Идентификаторы: `amocrm`, `bitrix`, `onec`, `office`, `whiteboard`, `planner`, `conference`, `servers`, `channels`, `bots`, `diary`, `family`, `legal`, `multiserver`, `totp`.

Сам ключ доступен в созданном приватном файле; в базе компании хранится только его хеш. Файл `/app/state/...` находится в постоянном томе коммерческого сервиса. Уже выданный ключ нельзя получить обратно из хеша. В закрытой админке License keys можно просмотреть состав, срок и привязку, а также отозвать ключ; создавать ключи следует указанной командой.

Один ключ привязывается к одному узлу. Дополнительные ключи суммируются. Истечение/отзыв ключа убирает платные инструменты из меню, но не удаляет пользовательские документы. Старые отметки установки прототипа не активируют платные модули.


### Удаление модуля и срок подписки

Администратор удаляет модуль кнопкой «Удалить» в каталоге для всего сервера. Данные и лицензия сохраняются; при активной подписке повторная установка не требует нового ключа. Платные операции отключаются сразу, включая открытые соединения. Дата и время окончания подписки отображаются в каталоге и разделе подписок в часовом поясе пользователя.
